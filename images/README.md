# Icons

This folder should contain the extension icons referenced in manifest.json:

- icon-16.png (16x16 pixels)
- icon-48.png (48x48 pixels)
- icon-128.png (128x128 pixels)

## Creating Icons

You can:
1. Create icons using any image editor (Photoshop, GIMP, Paint.net, etc.)
2. Use online icon generators
3. Use these icon generation tools:
   - https://www.favicon-generator.org/
   - https://icon.kitchen/

## Icon Recommendation

A simple design with a car and notepad icon works well. Example description:
- Background: Gradient (purple to blue)
- Icon: Simple car outline or notepad with checkmark
- Style: Flat design for clarity at all sizes
- Format: PNG with transparent background

## Installation

Once created, place the PNG files in this `images/` folder. The extension will use them in:
- Chrome toolbar (small icon)
- Extensions management page
- Shortcut icons

If icons are missing, Chrome will use a default placeholder.

Note: The extension will still work without custom icons, but they improve the visual appearance.
